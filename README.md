# Baby Cure — GitHub Pages Demo

Single-file Arabic RTL functional prototype. Open `index.html` directly or deploy the repository root with GitHub Pages.

Demo login: `admin` / `demo123`

## Important
This build stores data only in the browser `localStorage`. It is for fictional/demo data only and is **not** a production medical record system. Before real patient data, migrate to a secure server-side database and implement real authentication, authorization, audit logging, backups, encryption, and operational/security review.

Included demo modules: dashboard, 5 NICU incubators, admission, patient profile, care-level timeline, daily NICU sheet, medications/MAR, investigations, billing, payments, inventory, outpatient, staff/payroll summary, reports, search, settings.
