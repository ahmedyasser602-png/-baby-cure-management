# Baby Cure – NICU & Pediatric Center

Runnable UI prototype for Baby Cure. **Use fictional data only.** This prototype is not yet suitable for real patient records.

## Run on Replit
Import/upload this project, then run:

    npm install
    npm run dev

The Vite server binds to 0.0.0.0 for Replit preview.

## Included in this prototype
- Arabic RTL medical dashboard
- Five NICU incubator cards
- Demo patient census
- New NICU admission modal
- Initial navigation for outpatient, billing, inventory and payroll
- Display of agreed accommodation rates

## Next production milestones
Persistent PostgreSQL database, authentication/RBAC, audit log, full patient profile, daily NICU sheet, respiratory timeline, medication/MAR, inventory transactions, billing engine, payments, discharge, outpatient workflow, payroll and reports.
