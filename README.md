# Baby Cure v9 — Mobile Patient Profile

- Mobile-first responsive layout, including card-style tables on phones.
- Every child has a dedicated patient profile opened from Dashboard or Patients.
- Patient profile shows demographic/admission data for operational users, clinical sections for Admin/Doctor/Nurse, and finance for Admin/Accountant.
- After a new NICU admission, the new patient profile opens automatically.
- Core patient/admission data comes from Supabase. Clinical profile sections read Supabase tables when the signed-in role has permission.

Use fictional/test data until production security validation is complete.
